# Scientific provenance

This reduced public directory retains three traceability maps from the larger
development workspace:

- `RDL-T2C-v1.0.csv`: theory-to-code mapping;
- `RDL-FTM-v1.0.csv`: figure/table generation map; and
- `RDL-PRO-v1.0.csv`: output provenance map.

Historical planning, review, checkpoint, run-note and workflow-governance
material is intentionally excluded from the public release surface.
