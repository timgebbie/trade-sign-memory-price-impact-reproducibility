## Repeatability

Two consecutive complete executions of `scripts/run_all.py` in the same clean
runtime produced byte-identical regenerated files across:

- `data/`;
- `raw-outputs/`;
- `outputs/`;
- `figures/python/`;
- `diagnostics/`; and
- `tables/tex/`.

The deterministic public runner sets `SOURCE_DATE_EPOCH=0`, which also removes
the Matplotlib PDF creation-date drift observed when the target scripts were
run individually without that environment control.

F08 is not regenerated by the Python route. Its accepted TikZ source and
frozen PDF/PNG hashes are checked exactly by `scripts/00_verify_release.py`.
