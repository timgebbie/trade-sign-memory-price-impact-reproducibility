# RDL Table T04 Caption v1.0

Artefact status: diagnostic output.

**Controlled parameter register for the implemented and gated RDL targets.**
The table records baseline values, scenario grids, units or normalisations,
dependent outputs and status. Values are synthetic and dimensionless unless a
calendar-event unit is stated. Blank values for the propagator and lattice/PDE
controls are deliberate: those branches remain blocked, deferred or future
only. This is a reproducibility register, not an empirical calibration table.
Source: `registers/RDL-PAR-v1.1.csv`; staged by `scripts/RDL-TAB.py`.
